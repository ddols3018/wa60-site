Privacy Policy

Last updated: October 9, 2026

Overview

WA60 Uploader ("the application") is a private tool operated by Chris Lee (Missiosoft) to publish videos to the Wellness After 60 YouTube channel. It is used solely by the channel owner on the owner's own computer.

Google user data

The application uses the YouTube Data API with the owner's consent to (1) upload videos to the owner's channel, (2) update the title, description, tags, and privacy status of those videos, and (3) post comments from the owner's channel. Access tokens are stored only on the owner's computer and are never transmitted to any third party.

Data collection

The application does not collect, store, sell, or share any personal information from any person. It has no database, no analytics, and no server. No data about viewers of the channel is accessed.

Third parties

No Google user data is shared with, transferred to, or sold to any third party. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The channel owner can revoke the application's access at any time at myaccount.google.com/permissions or by deleting the locally stored token file.
